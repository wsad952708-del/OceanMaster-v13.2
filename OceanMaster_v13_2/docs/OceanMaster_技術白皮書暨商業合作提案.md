# 第二章　OceanMaster 能幫你做什麼

以下每一項功能，都已實際開發完成，並通過內部自動化測試（非第三方獨立審計）。

不是簡報、不是構想、不是概念驗證——是寫好的、跑得動的系統。

## 2.1 每天告訴你去哪裡

| 功能 | 怎麼幫你 |
|------|---------|
| **每日 Top 20 漁場推薦** | 每天從衛星資料分析整個作業海域，列出最值得去的 20 個點，附座標、距離、預估魚種 |
| **10 種魚種全覆蓋** | 黃鰭鮪、大目鮪、正鰹、長鰭鮪、赤魷、日本魷、鬼頭刀、旗魚、竹筴魚、秋刀魚 — 你在抓的魚，系統都涵蓋 |
| **魚種出現機率** | 用**西太平洋漁業組織公開漁獲統計**校準，告訴你每個點每種魚出現的機率是多少 — 不是猜的，是算的 |
| **資料可信度評分** | 每天自動評估數據品質（A / B / C / D），讓你知道今天的推薦有多可靠 |

## 2.2 讓你安全、省油地到達漁場

| 功能 | 怎麼幫你 |
|------|---------|
| **最佳航線規劃** | 幫你算出從目前位置到推薦漁場的最省油航線 |
| **經濟海域自動迴避** | 航線自動避開他國 EEZ（經濟海域），避免被扣船、被罰款 |
| **四級安全評估** | 每個推薦漁場標記安全等級 — 安全 / 注意 / 警戒 / 禁入 — 安全的才推給你 |
| **氣海況整合** | 風場、海況、波浪、氣壓同步分析，有颱風或惡劣海況自動拉低推薦分數 |

## 2.3 比老船長多看到的東西

這些是衛星和 AI 能看到、人眼看不到的東西：

| 分析能力 | 對你的意義 |
|---------|----------|
| **深層水溫分析（100m）** | 大目鮪、長鰭鮪待在深水層，表面溫度不能代表一切。系統分析 100 公尺深度的水溫，找到牠們偏好的溫度帶 |
| **黑潮即時追蹤** | 黑潮是太平洋漁場的命脈。系統每天追蹤黑潮位置、強度、擺動方向。黑潮邊緣就是魚路 |
| **渦旋（暖/冷水團）偵測** | 偵測海面上的中尺度渦旋，判斷成熟度。渦旋邊緣營養上升，是鮪魚群聚的地方 |
| **冷暖水交界偵測** | 找出海面上溫度急劇變化的地方（鋒面）。鋒面前方是餌料魚聚集區，鮪魚會跟著來 |
| **浮游生物鏈推估** | 從衛星偵測的葉綠素推算浮游動物在哪裡 → 推斷小魚在哪裡 → 推斷大魚會去哪裡 |
| **魚類垂直遷移** | 分析魚群晝夜之間的上下移動行為，告訴你什麼時間在什麼深度下鉤最有效 |
| **SST 超解析度** | 架構已實作（SRGAN），⚠️ **模型未訓練**——目前此功能尚未上線，待取得足夠訓練資料後啟用 |

## 2.4 氣候大尺度校準

| 功能 | 做什麼 |
|------|-------|
| **聖嬰 / 反聖嬰校正** | El Niño 年黃鰭鮪漁場南移、黑潮減弱；La Niña 年相反。系統自動根據當前氣候狀態調整預測 |
| **太平洋十年震盪（PDO）** | 考慮 10-20 年週期的北太平洋溫度長期變化 |
| **印度洋偶極（IOD）** | 考慮印度洋對西太平洋的間接影響 |

> 這些氣候校正讓系統不只看「今天的海」，還考慮「今年的大氣候」。

## 2.5 颱風後的黃金窗口

颱風過後 48-72 小時，海水被攪動、營養上升，魚群重新聚集。系統會：

- 偵測颱風過後的海域
- 計算窗口開啟和關閉時間
- 推薦颱風後最佳漁場位置

## 2.6 月相影響

魚的活動跟月亮有關。系統內建 10 種魚的月相敏感度模型：

- 滿月：魷魚趨光性降低、延繩釣效率變化
- 新月：魷魚集魚燈效果最佳

## 2.7 每日簡報與儀表板

| 輸出 | 說明 |
|------|------|
| **文字版漁場簡報** | 自動產生中文版「今日漁場分析報告」，LINE 群組就能看 |
| **互動地圖儀表板** | 手機 / 平板 / 電腦打開瀏覽器就能用，不需安裝 App |
| **API 串接** | 可以接到 LINE Bot、自家系統、任何平台 |
