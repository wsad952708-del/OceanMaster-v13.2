# OceanMaster v13.2 — 完整安裝教學（從零開始）

> 適合對象：有基本電腦操作能力，但不熟悉 Python 的使用者。

---

## 第一步：安裝 Python

### Windows

1. 前往 https://www.python.org/downloads/
2. 下載 Python 3.11（或 3.10+）
3. 安裝時**勾選** "Add Python to PATH" ⚠️ 這很重要！
4. 安裝完成後，打開 CMD 或 PowerShell，輸入：
   ```
   python --version
   ```
   應該顯示 `Python 3.11.x`

### macOS

```bash
brew install python@3.11
```

### Linux (Ubuntu)

```bash
sudo apt update
sudo apt install python3.11 python3.11-venv python3-pip
```

---

## 第二步：取得 CMEMS 帳號（免費）

OceanMaster 需要衛星數據，最主要的來源是 Copernicus Marine Service：

1. 前往 https://data.marine.copernicus.eu/register
2. 註冊免費帳號
3. 記下你的 **用戶名** 和 **密碼**

---

## 第三步：設定環境

1. 把 `OceanMaster_v13_2` 資料夾放到你想要的位置（例如 `C:\OceanMaster`）

2. 打開 CMD/PowerShell，進入該資料夾：
   ```
   cd C:\OceanMaster\OceanMaster_v13_2
   ```

3. 建立 Python 虛擬環境：
   ```bash
   python -m venv venv
   ```

4. 啟動虛擬環境：
   ```bash
   # Windows PowerShell:
   .\venv\Scripts\Activate.ps1

   # Windows CMD:
   venv\Scripts\activate.bat

   # macOS/Linux:
   source venv/bin/activate
   ```
   成功後，命令列前面會出現 `(venv)`

5. 安裝套件：
   ```bash
   pip install -r requirements.txt
   ```
   ⏱️ 第一次安裝需要 5-10 分鐘，取決於網路速度。

---

## 第四步：設定認證

1. 複製環境變數模板：
   ```bash
   # Windows:
   copy .env.example .env

   # macOS/Linux:
   cp .env.example .env
   ```

2. 用文字編輯器打開 `.env`，填入你的 CMEMS 帳號：
   ```
   CMEMS_USER=你的用戶名
   CMEMS_PASS=你的密碼
   OCEANMASTER_API_KEY=隨便打一串隨機文字（用於 API 認證）
   ```

---

## 第五步：啟動系統

```bash
# 確保虛擬環境已啟動（前面有 (venv)）
python web_server.py
```

看到類似以下訊息就是成功了：
```
INFO:     OceanMaster v13.2 starting...
INFO:     Uvicorn running on http://0.0.0.0:8000
```

🎉 你應該能看到專業的深色主題儀表板！（含 T100 深層水溫、溫度梯度等海鷹級分析）

## 常見問題

### Q: 安裝 pip install 時出錯？

```bash
# 升級 pip
python -m pip install --upgrade pip

# 如果某個套件裝不了，先裝其他的
pip install -r requirements.txt --ignore-installed
```

### Q: 出現 `ModuleNotFoundError`？

確認虛擬環境已啟動（前面有 `(venv)`）：
```bash
# Windows:
.\venv\Scripts\Activate.ps1
```

### Q: 儀表板地圖是空白的？

- 確認有網路連線
- 確認瀏覽器可以存取 `cdn.jsdelivr.net`（地圖 JS 庫）
- 首次啟動需要時間下載衛星數據

### Q: CMEMS 連線逾時？

Copernicus 有時候會比較慢，系統會自動使用快取或氣候態數據作為備援。

### Q: 想要訓練 ML 模型？

```bash
# 用合成數據訓練（測試用）
python train_and_validate.py --all

# 用真實數據訓練（需要先下載 CPUE 數據）
python train_and_validate.py --all --data-path data/real/fao_cpue.csv
```

> 💡 v13.2 使用 **59 維特徵** ML pipeline（含 T100 深層水溫、梯度強度、表面-深層溫差、CHL 延遲），支援 6 種物種的 stacking ensemble 模型。

### Q: 想要 Docker 部署？

```bash
# 開發環境
docker-compose up -d

# 生產環境
docker-compose -f docker-compose.production.yml up -d --build
```

## 每日使用流程

1. 啟動虛擬環境 → 啟動 `web_server.py`
2. 開啟 `http://localhost:8000/web/dashboard_v3.html`
3. 選擇目標魚種
4. 查看熱點地圖 + 食物鏈時間軸
5. 點擊熱點查看 SHAP 解釋

### 自動化（進階）

設定排程自動跑預測：

```bash
# Windows Task Scheduler:
# 每 6 小時執行一次
python main_v10_3.py --run-now

# Linux cron:
0 */6 * * * cd /opt/oceanmaster && venv/bin/python main_v10_3.py --run-now
```
