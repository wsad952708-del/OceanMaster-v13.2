> **⚠️ 部署模型的 Spatial CV R² 全部為負**，代表 Stacking Ensemble 在未見過的地理區域上預測能力不如區域平均值。
> 因此系統融合權重已設定為 **80% 物理 HSI + 20% ML**，以物理海洋學為主導。
>
> **為什麼不是 100:0（完全停用 ML）？**
> Spatial CV 測試的是最嚴苛的情境：模型在**完全未見過的 10°×10° 地理區塊**上的表現。
> 但遠洋漁船多在固定海域作業（如西太平洋鮪魚帶），實際操作中不太可能進入模型完全未見過的區塊。
> 在訓練分佈的海域內，模型可能仍捕捉到一些有用的模式，但**這一點尚無經過空間切割驗證的數據支持**。
> 20% 是保守的低影響權重：若 ML 預測錯誤，80% 的物理 HSI 仍然主導結果，損害有限。
> 若未來取得實海漁獲回饋可重新校準，或在確認 ML 無正面貢獻時調為 100:0。

## 一、系統概述

OceanMaster 是一套 **AI 驅動的遠洋漁場預測系統**，透過整合 12 種衛星與海洋數據源，結合機器學習模型與海洋學理論，為遠洋漁船提供**每日漁場熱點預測**。

系統目前支援 **6 種目標物種** 的漁場預測，涵蓋鮪魚（4 種）和魷魚（2 種）。6 種均具備 ML Stacking 模型：其中黃鰭鮪、大目鮪、長鰭鮪以 WCPFC 真實漁獲資料訓練（Spatial CV R² 為負，詳見 §17 已知限制）；正鰹及 2 種魷魚以合成資料訓練（R² 僅代表公式擬合）。另有 3 種台灣近海物種（鬼頭刀、旗魚、竹筴魚）為純物理評估，無 ML 模型。

### 規模數據

| 指標 | 數據 |
|------|------|
| 程式碼規模 | 約 70,000 行（Python 為主） |
| 引擎模組 | 110 個獨立科學/AI 引擎 |
| 機器學習模型 | 6 個 Stacking Ensemble 預訓練模型（鮪魚 59 特徵、魷魚 47 特徵）+ 4 個 12 特徵 legacy fallback（主模型預測發生任何錯誤時自動切換，觸發條件為 `except Exception`）+ 6 個 Scaler |
| 自動化測試 | 工程健全性測試通過（模組載入、函式呼叫、資料流，非預測準確性驗證） |
| 特徵維度 | FeatureEngineer 產生 **59 個科學特徵**；鮪魚模型訓練於 59 特徵，魷魚模型訓練於 47 特徵，預測時自動對齊 |

## 三、核心演算法引擎

### 3.1 物種棲地適合度模型 (HSI)

每個物種有獨立的 **棲地適合度指數 (Habitat Suitability Index)** 模型：

- **SST 適溫曲線** — 根據各物種最適水溫計算高斯適合度（例：黃鰭鮪最適 28°C，長鰭鮪最適 18.5°C）
- **葉綠素指標** — 反映食物鏈底層的浮游植物豐度
- **溫躍層深度** — 判斷垂直棲地空間
- **代謝指數 Φ (Deutsch 2015)** — 結合溫度與溶氧，評估魚類在該水域的生理可行性
- **月相效應** — 新月時鰹魚/魷魚活性增加，滿月時下降（魷魚影響尤為顯著）
- **ENSO 校正** — 根據聖嬰/反聖嬰現象動態調整各物種的適合度權重

### 3.2 機器學習 Stacking Ensemble

系統使用**多模型堆疊集成**進行漁場預測：

```
第一層（最多 6 個基礎學習器）：
  ├── Random Forest（隨機森林）
  ├── Gradient Boosting（梯度提升）
  ├── XGBoost（極端梯度提升）
  ├── LightGBM（輕量梯度提升）
  ├── CatBoost（類別特徵提升）← optional
  └── Ridge（嶺回歸）
  
第二層（元學習器）：
  └── RidgeCV（嶺回歸交叉驗證）
      → 融合基礎模型的預測結果
```

- 輸入：**59 維科學特徵向量**
- 輸出：CPUE 預測值（0-1 標準化單位努力漁獲量）
- 每個物種有獨立的模型（目前 6 個：黃鰭鮪、大目鮪、長鰭鮪、鰹魚、北太魷魚、日本魷魚）
- 所有模型使用 **HMAC-SHA256 簽章**防篡改

### 3.3 59 維科學特徵向量

每一個預測點都會計算以下 59 個科學特徵：

**基礎環境 (5)**
- 海面溫度 (SST)、葉綠素 (CHL)、海面高度 (SSH)、海流速度、海流方向

**衍生物理 (8)**
- SST 梯度、CHL 梯度、鋒面強度、FTLE (拉格朗日相干結構)、FTLE 脊線
- 溫躍層深度、20°C 等溫深度 (D20)、混合層深度 (MLD)

**距離特徵 (4)**
- 到最近鋒面、渦旋、海山、陸棚陡坡的距離

**地形特徵 (3)**
- 海底深度、海底坡度、海底粗糙度

**時間特徵 (5)**
- 月相、季節正弦/餘弦編碼、日的年份正弦/餘弦編碼

**時序特徵 (2)**
- SST 7天趨勢、CHL 30天異常

**交互特徵 (3)**
- SST×CHL、鋒面×FTLE、SSH×溫躍層

**窗口統計 (3)**
- SST 局部標準差、CHL 局部平均、海流局部平均

**遙測/AIS (2)**
- AIS 漁船密度、VIIRS 夜間燈光密度

**科學進階 (10)**
- 月光-CPUE 修正、浮游動物指數、產卵季節、ENSO 指標 (ONI)
- 氧最低帶壓縮、渦旋營養富集、垂直遷移可及深度 (DVM)
- 鹽度鋒面強度、生產力鋒面、棲地壓縮比

**台灣特化 (2)**
- 黑潮距離、台灣海峽指標（高斯建模）

**深層海洋 (4)**
- 100m 水溫 (T100)、溫度梯度強度、SST-T100 溫差、15天前CHL

**進階生態互動 (8)**
- 月光 DVM 抑制、風暴後藻華、海山-海流交互、餌料溫躍層陷阱
- 潮汐混合指數、SST 季節變化率、聚合代理指標、晨昏時長

## 四、進階物理與生態引擎

### 4.1 海洋物理

| 引擎 | 功能 |
|------|------|
| **渦旋偵測器** | 從 SSH 場自動偵測反氣旋/氣旋渦旋中心、半徑、旋轉方向 |
| **Okubo-Weiss 參數** | 計算海流形變場，識別渦旋核心 vs. 應變帶 |
| **FTLE / 拉格朗日移流** | 計算有限時間 Lyapunov 指數，找出海洋中的「隱形牆」（輸運屏障） |
| **聚合帶偵測** | 識別海流匯合區域，這裡是營養物和餌料生物聚集的地方 |
| **棲地壓縮指數** | 當氧最低帶上升+溫躍層變淺，魚被壓縮到表層薄層 → 易捕 |
| **海洋熱浪偵測** | 當 SST 異常偏高持續 5+ 天，標記為海洋熱浪事件 |
| **混合層深度預報** | 估算未來混合層深度變化 |
| **SST 變化率偵測** | 偵測湧升流事件（SST 快速下降=深層冷水上升=營養鹽暴增） |
| **水團分類器** | 辨識不同水團（黑潮暖水、沿岸冷水、南海水等），不同魚種偏好不同水團 |

### 4.2 黑潮引擎（台灣特化）

專為台灣周邊海域設計：
- 計算每個點到黑潮主軸的距離
- 偵測黑潮蛇行（meander）產生的暖水舌和冷水入侵
- 台灣海峽指標使用**非等向高斯函數**建模（東西窄、南北寬，符合海峽實際形狀）

### 4.3 生態模型

| 引擎 | 功能 |
|------|------|
| **食物鏈級聯預測** | NPZ 模型（營養鹽→浮游植物→浮游動物）預測餌料分佈 |
| **垂直遷移模型 (DVM)** | 模擬鮪魚/餌料的晝夜垂直遷移，受月光和溫躍層影響 |
| **鮪魚行為模型** | 考慮吃食、巡游、生殖三種行為模式 |
| **產卵棲地** | 根據物種特定的產卵季節和水溫偏好強化預測 |
| **浮游動物代理** | 用 CHL + SST + 混合層估算浮游動物豐度 |
| **渦旋生物成熟度** | 渦旋形成後約 2-4 週才會產生營養富集效應 |
| **微型遊泳生物模型** | 3D 棲地模型估算中層餌料生物分佈 |
| **聲學深度代理** | 估算深散射層 (DSL) 位置，間接推測餌料密集層 |

### 4.4 颱風模組

| 引擎 | 功能 |
|------|------|
| **颱風追蹤器** | 即時追蹤颱風路徑 + 72 小時預報 |
| **颱風後黃金漁場** | 颱風過後 3-7 天，強烈混合帶出深層營養鹽 → 藻華爆發 → 餌料聚集 → 黃金漁場 |

## 五、SHAP 可解釋性

每一個漁場預測都附帶 **SHAP (SHapley Additive exPlanations)** 分析：

- 解釋「為什麼這個點被預測為好的漁場」
- 列出貢獻最大的前 5 個因素（例：「SST 接近 28°C +0.15」「渦旋邊緣豐富 +0.08」）
- 用白話文告訴船長：「這裡因為水溫適合、渦旋帶來營養鹽、拉格朗日分析顯示有鋒面聚集帶」

## 十、資料品質與驗證

| 機制 | 說明 |
|------|------|
| **多源融合** | 同一變數（如 SST）取多個數據源的加權平均，降低單源故障風險 |
| **降級回報** | 若某數據源暫時不可用，自動改用替代源或歷史氣候值 |
| **NaN/Inf 清洗** | 所有數據在計算前進行異常值清理 |
| **WCPFC 歷史驗證** | 用西太平洋漁業委員會的歷史捕獲數據驗證模型預測準確性 |
| **SHAP 一致性檢查** | 確保模型的特徵重要性排序符合漁業科學常識 |
| **Bootstrap 信賴區間** | CPUE 預測附帶統計信賴區間 |
| **OBIS 物種驗證** | 與全球海洋生物多樣性資訊系統交叉驗證物種分佈預測 |
