## 二、安裝系統（10 分鐘）

### 步驟 1：打開終端機

**Windows：** 按 `Win+R` → 輸入 `cmd` → Enter
**Mac：** 打開「終端機」App

### 步驟 2：進入專案資料夾

```bash
cd 你放專案的路徑\OceanMaster_v13_2
```

例如：
```bash
cd C:\Users\user\Desktop\好像快好了\OceanMaster_v13_2
```

### 步驟 3：建立虛擬環境（隔離套件）

```bash
# 建立
python -m venv venv

# 啟動（Windows）
venv\Scripts\activate

# 啟動（Mac/Linux）
source venv/bin/activate
```

啟動後，終端前面會出現 `(venv)` 字樣 ← **這代表成功了**

### 步驟 4：安裝所有套件

```bash
pip install -r requirements.txt
```

> ⏱️ 這一步大概 3-5 分鐘，取決於網速。
> 會看到一堆東西在裝，正常的，等它跑完就好。

### 步驟 5：確認安裝成功

```bash
python -c "from main_v10_3 import OceanMasterPipeline; print('✅ 安裝成功！')"
```

如果看到 `✅ 安裝成功！` 就對了。

## 四、第一次跑預測（看它能幹嘛）

## 六、用 API 串接你的系統

### API 端點一覽

| 方法 | 路徑 | 用途 |
|------|------|------|
| GET | `/health` | 檢查系統狀態 |
| POST | `/predict` | 跑一次完整預測 |
| GET | `/hotspots` | 取得最新漁場列表 |
| GET | `/hotspots/{species}` | 依魚種篩選 |
| GET | `/species` | 列出支援的魚種 |
| POST | `/retrain` | 查看資料蒐集狀態（⚠️ 自動微調已停用，僅回報累積筆數） |

### 範例：取得最新漁場（Python）

```python
import requests

API = "http://localhost:8000"
KEY = "my-secret-key-12345"
headers = {"X-API-Key": KEY}

# 取得最新熱點
resp = requests.get(f"{API}/hotspots", headers=headers)
hotspots = resp.json()

for hs in hotspots[:3]:
    print(f"📍 {hs['lat']}°N {hs['lon']}°E — HSI: {hs['hsi']}")
```

### 範例：跑一次完整預測

```python
resp = requests.post(f"{API}/predict", headers=headers, json={
    "species": "yellowfin",
    "mode": "offshore",
    "lat_range": [5, 35],
    "lon_range": [120, 175],
})
result = resp.json()
print(f"狀態: {result['status']}")
print(f"找到 {result['n_hotspots']} 個漁場")
```

## 七、餵養真實漁獲數據（為未來改進做準備）

> ⭐ **這是未來讓 AI 變準的基礎。** 現階段回報的漁獲資料會被儲存起來，供日後有監督的重新訓練使用。資料蒐集得越完整，未來重訓練後的預測準確度就越有改善的基礎。

### 7.1 準備你的漁獲數據

你需要記錄每次出海的以下資訊：

```
必要欄位：
├── 日期（例：2026-03-15）
├── 緯度（例：23.4）
├── 經度（例：131.2）
├── 魚種（例：yellowfin）
├── CPUE（每單位努力漁獲量，例：每千鉤 12.5 尾）
│
選填欄位（有的話更好）：
├── 漁獲重量 kg
├── 作業時數
├── 鉤數
└── 備註
```

### 7.2 方法一：用 Python 腳本餵數據（推薦）

把你的漁獲紀錄整理成 CSV，然後跑這個腳本：

```python
# feed_catch_data.py — 餵入真實漁獲數據

import csv
from engine.validation_tracker import PredictionValidator

validator = PredictionValidator()

# 讀你的 CSV
with open("我的漁獲紀錄.csv", encoding="utf-8") as f:
    reader = csv.DictReader(f)
    count = 0
    for row in reader:
        validator.record_observation(
            lat=float(row["緯度"]),
            lon=float(row["經度"]),
            date=row["日期"],             # 格式：2026-03-15
            species=row["魚種"],           # yellowfin / bigeye / skipjack
            actual_cpue=float(row["CPUE"]),
            catch_kg=float(row.get("重量kg", 0)),
            effort_hours=float(row.get("作業時數", 0)),
        )
        count += 1

print(f"✅ 已匯入 {count} 筆漁獲紀錄")

# 看看現在的準確度
metrics = validator.compute_metrics()
if metrics["status"] == "ok":
    print(f"📊 命中率: {metrics['hit_rate']:.1%}")
    print(f"📊 相關性: {metrics['spearman_rho']:.3f}")
    print(f"📊 配對數: {metrics['n_matched']}")
else:
    print(f"⏳ 數據還不夠（目前 {metrics['n_matched']} 筆），需要至少 5 筆配對成功")
```

### 你的 CSV 長這樣：

```csv
日期,緯度,經度,魚種,CPUE,重量kg,作業時數
2026-03-15,23.4,131.2,yellowfin,12.5,850,8
2026-03-15,23.4,131.2,bigeye,3.2,280,8
2026-03-16,22.8,129.5,yellowfin,8.7,620,6
2026-03-17,24.1,132.8,bigeye,15.1,1200,10
```

## 八、讓 AI 變聰明（資料蒐集階段）

### 資料蒐集機制

系統有一個 **增量學習引擎** (`engine/incremental_learner.py`)：

```
你回報漁獲 → 系統記錄 → 資料持續累積
                               ↓
                      儲存供未來有監督的重新訓練使用
```

> ⚠️ **重要說明：自動微調功能目前已停用**
> 為了安全起見，系統目前只會**蒐集和儲存**漁獲回報資料，**不會自動更新 AI 模型**。
> 原因：資料量不足時自動更新可能讓模型變差，需要先建立完整的驗證流程再啟用。
> **你該做的事**：繼續回報漁獲資料，等資料量足夠後，會進行有監督的重新訓練。

### 查看資料累積狀態

```python
from engine.incremental_learner import maybe_finetune

# 查看累積了多少筆回報（不會觸發微調，只看狀態）
maybe_finetune(model_dir="models")
```

### 查看 AI 學習進度

```python
from engine.validation_tracker import PredictionValidator

v = PredictionValidator()

print(f"""
📊 OceanMaster 準確度報告（黃鰭鮪）
```

### Q2：CMEMS 數據下載失敗？

1. 確認帳號密碼正確
2. 確認 `.env` 檔有沒有多餘的空格
3. 試試看能不能登入 https://data.marine.copernicus.eu
4. CMEMS 偶爾會維護，等一下再試

### Q3：預測要跑很久？

| 原因 | 解法 |
|------|------|
| 第一次要下載所有衛星數據 | 正常，後續會用快取 |
| 網路慢 | 換好一點的網路 |
| 分析區域太大 | 縮小 lat/lon 範圍 |
| 電腦太慢 | 關掉其他程式 |

### Q5：怎麼改分析區域？

編輯 `.env`：
```env
PREDICTION_LAT_MIN=5      # 南界
PREDICTION_LAT_MAX=35     # 北界
PREDICTION_LON_MIN=120    # 西界
PREDICTION_LON_MAX=175    # 東界
```

或在程式裡直接指定：
```python
pipeline = OceanMasterPipeline(
    lat_range=(15, 30),    # 只看 15°N ~ 30°N
    lon_range=(125, 145),  # 只看 125°E ~ 145°E
    species="yellowfin",
)
```
