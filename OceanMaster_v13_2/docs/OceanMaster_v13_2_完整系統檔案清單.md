## 九、輸出與儀表板

### 儀表板功能總覽

OceanMaster 配備兩套儀表板（v1 戰情室 + v2 進階版），合計 **7,000+ 行前端程式碼**，提供以下互動功能：

#### 🗺️ 互動式地圖功能

| 功能 | 說明 |
|------|------|
| **漁場熱點標記** | 每日自動標記 Top 20 漁場熱點，顏色表示 HSI 評分（綠→黃→紅） |
| **SST 疊圖** | 海面溫度衛星場疊加在地圖上，可開關切換 |
| **熱力圖模式** | 切換為漁場密度熱力圖，一目了然看出漁場集中區 |
| **EEZ 邊界顯示** | 顯示各國 200 海浬經濟海域邊界，防止越界 |
| **點擊飛航** | 點擊任一漁場熱點自動放大到該位置 |
| **圖層切換** | 自由開關 SST、CHL、SSH、漁場、EEZ 等圖層 |

#### 📊 資料面板功能

| 功能 | 說明 |
|------|------|
| **漁場排行榜** | 按 HSI 評分排列所有漁場熱點，顯示排名、經緯度、評分 |
| **物種篩選** | 一鍵切換黃鰭鮪、大目鮪、長鰭鮪、鰹魚、魷魚的漁場顯示 |
| **漁場卡片** | 每個推薦漁場顯示詳細卡片：HSI 分數、水溫、深度、風浪、安全等級 |
| **統計摘要** | 即時顯示今日漁場數量、平均 HSI、最佳物種、安全區域比例 |
| **星級評分** | 每個漁場以 1-5 星直覺顯示推薦程度 |

#### 🔬 科學分析功能

| 功能 | 說明 |
|------|------|
| **SHAP 解釋** | 點擊任一漁場可查看「為什麼 AI 推薦這裡」的科學分析（哪個因素貢獻最多） |
| **食物鏈分析** | 顯示該漁場的營養鹽→浮游植物→浮游動物→餌料魚生態鏈狀態 |
| **食物鏈時間線** | 過去 30 天的食物鏈各層級變化趨勢圖 |
| **DVM 剖面** | 魚群日夜垂直遷移深度剖面圖 — 顯示目標魚群在哪個深度 |
| **月相面板** | 當前月相與各物種活性關聯分析 |

#### 🌊 海況與安全功能

| 功能 | 說明 |
|------|------|
| **即時海況** | 當前海面風速、浪高、洋流速度、水溫、鹽度 |
| **海況格網** | 將分析區域切割為格網，分色顯示各區安全等級 |
| **颱風追蹤** | 即時颱風位置、路徑預報、72 小時預測圓錐 |

#### 🦑 魷釣專用功能
