# OceanMaster 智慧漁場預測系統 — 船東功能說明書

> **本文件用途**：讓船東了解系統具備的所有功能與能力  
> **重要聲明**：本文件不含任何演算法細節、API 金鑰或商業機密  
> ✅ 所有列出的功能均已通過程式碼驗證，確實存在於系統中

---

## 一、系統能做什麼？（一句話）

**輸入衛星資料 → 系統自動分析 → 告訴你哪裡有魚、最佳路線怎麼走、安不安全**

## 三、衛星資料擷取（系統自動取得）

系統自動從以下來源擷取資料，船上不需手動操作：

| 資料 | 來源 | 用途 |
|------|------|------|
| 海面溫度 (SST) | NASA OISST / MUR 1km / CMEMS | 判斷魚群喜好水溫區域 |
| 葉綠素濃度 (CHL) | MODIS / VIIRS | 判斷浮游植物密度 → 餌料豐富度 |
| 海面高度 (SSH) | CMEMS 哥白尼 | 偵測渦旋、洋流 |
| 海流速度/方向 | CMEMS 海流場 | 航線規劃、延繩漂流預測 |
| 溫躍層深度 | CMEMS 3D 水溫 | 判斷魚群聚集深度 |
| 浪高/浪向 | WaveWatch III | 安全評估 |
| 風速/風向 | 氣象資料 | 安全評估 + 作業條件 |
| 夜間燈光 | VIIRS DNB | 偵測集魚燈（魷魚漁船定位） |
| 海底地形 | GEBCO | 海山偵測、漁場地形分析 |
| Argo 剖面 | 全球 Argo 浮標 | 0-2000m 垂直水溫/鹽度 |
| 降雨量 | GPM 衛星 | 颱風後漁場評估 |
| 鹽度 | CMEMS SSS | 鹽度鋒面偵測 |

> 所有資料擷取均有**自動重試**和**降級回報**機制 — 當某個資料源不可用時，系統會自動切換備用來源繼續運作。

## 四、海洋分析能力

### 🌊 物理海洋分析

| 功能 | 說明 | 船東怎麼用 |
|------|------|-----------|
| **SST 鋒面偵測** | 自動找出冷暖水交界處 | 鋒面是魚群聚集的主要位置 |
| **FTLE 拉格朗日分析** | 追蹤海水粒子的移動路徑 | 找出餌料和漂浮物聚集的海域 |
| **渦旋自動偵測** | 識別反氣旋/氣旋渦旋中心 | 渦旋邊緣常有大魚群 |
| **Okubo-Weiss 形變** | 區分渦旋核心與剪切帶 | 精確定位渦旋最佳釣點 |
| **聚合帶偵測** | 偵測海流匯合區域 | 營養物和餌料聚集帶 |
| **湧升流偵測** | SST 快速下降 = 深層冷水上升 | 營養鹽暴增 → 食物鏈活化 |
| **黑潮分析**（台灣特化）| 黑潮主軸距離、蛇行偵測 | 追蹤黑潮漁場位置 |
| **水團分類** | 辨識黑潮暖水、沿岸冷水 | 不同水團適合不同魚種 |
| **溫躍層/混合層計算** | 計算溫度躍變和混合層深度 | 決定鉤深和魚群位置 |
| **棲地壓縮指數** | 氧最低帶和溫躍層夾擠魚群 | 魚群被壓到表層時最容易捕獲 |
| **海洋熱浪偵測** | SST 異常持續 5+ 天 | 熱浪區域魚群會遷移 |

### 🐟 生態與魚群行為

| 功能 | 說明 | 船東怎麼用 |
|------|------|-----------|
| **HSI 漁場評分** | 每種魚有獨立的棲地適合度評分 | 快速看哪裡分數最高就去哪裡 |
| **產卵棲地評估** | 評估各海域的產卵適合度 | 產卵季節抓繁殖群 |
| **食物鏈模擬** | 營養鹽→浮游植物→浮游動物 | 預測哪裡餌料最多 |
| **NPZ 生態動力模型** | 三層簡化的海洋食物網 | 推算餌料密集區域 |
| **垂直遷移模型 (DVM)** | 模擬魚群體晝夜上下游動 | 知道白天/晚上魚在哪個深度 |
| **月相效應** | 新月/滿月對不同魚種的活性影響 | 推薦最佳作業日 |
| **洄游路徑預測** | 季節性洄游路線預測 | 追蹤目標魚群的移動方向 |
| **魚類行為模式** | 吃食、巡游、生殖三種模式 | 不同行為有不同最佳捕獲策略 |
| **渦旋生物成熟度** | 渦旋形成後 2-4 週最佳 | 追蹤渦旋年齡，抓最佳漁期 |
| **浮游動物代理** | 用衛星資料推算浮游動物量 | 餌料指標 |
| **微型遊泳生物分佈** | 200-1000m 餌料生物 | 深海捕撈參考 |
| **ENSO 校準** | 聖嬰/反聖嬰對各魚種的影響修正 | 大尺度氣候事件的漁場調整 |

## 五、AI 預測引擎

| 功能 | 說明 |
|------|------|
| **Stacking Ensemble** | 5 層堆疊式機器學習（結合多個演算法取最佳預測） |
| **59 維特徵分析** | 系統從衛星資料自動衍生 59 個科學特徵進行預測 |
| **WCPFC 真實資料驗證** | 鮪魚模型以 WCPFC 1950-2018 真實漁獲資料訓練 |
| **ConvLSTM 時空預報** | ⚠️ 架構已實作，尚未整合進預測管線（無驗證指標） |
| **U-Net 漁場分割** | ⚠️ 架構已實作，尚未整合進預測管線（無驗證指標） |
| **TransFish 融合模型** | ⚠️ 架構已實作，尚未整合進預測管線（無驗證指標） |
| **SHAP 可解釋分析** | 每個推薦漁場附帶科學解釋（⚠️ 解釋基於基礎模型，非最終融合輸出） |
| **Species Probability** | 各物種出現機率 + 不確定性量化 |
| **HSI + ML 融合** | 規則式 HSI 分數和 ML 預測加權融合（80:20 物理:ML），取兩者優點 |
| **增量學習** | 每次航次帶回漁獲回報，資料持續蓄積供未來模型改進（目前為資料蒐集階段） |
| **Conformal Prediction** | 預測結果附帶信賴區間（⚠️ 校準集為隨機切割，在未見過的海域信賴區間可能失效） |

> **⚠️ AI 預測驗證狀態說明**：
> - 鮪魚模型（黃鰭、大目、長鰭）以 WCPFC 1950-2018 歷史資料訓練。**Spatial CV R² 為負**（黃鰭 -0.21、大目 -0.41、長鰭 -0.06），代表模型在未見過的海域預測能力不足。因此融合權重已從 40:60 調整為 **80:20（物理 HSI 主導）**。Holdout R² 約 0.60-0.62，但使用隨機切割（非空間切割），可能存在地理洩漏，不應作為模型泛化能力的依據。
> - 鰹魚、魷魚模型使用**合成資料訓練**，其 R²（0.86-0.92）僅代表模型對合成公式的擬合能力，**不代表真實海洋預測能力**。
> - WCPFC 歷史資料跨度 70 年，未做 catchability coefficient 校正；Holdout 為隨機切割（非時間切割）。
> - **系統核心優勢在物理海洋分析層**（鋒面、FTLE、渦旋、溫躍層），這些基於物理學原理，不依賴統計驗證。ML 模組作為輔助加權存在。

### 🚢 白話版：這套系統能做什麼、不能做什麼

**✅ 系統做得到的事：**
- 告訴你今天**哪邊的海水溫度、洋流、鋒面條件比較適合目標魚種**
- 告訴你**哪裡有溫度鋒面（冷暖水交界）、渦旋邊緣、上升流**——這些是魚群聚集的物理條件
- 告訴你**出海是否安全**（風浪、颱風、瘋狗浪風險）
- 在你**常去的海域**，AI 預測有一定參考價值

**⚠️ 系統做不到的事：**
- **不能保證推薦的漁場一定有魚**——分數 0.90 代表「今天這片海域裡條件最好的地方」，不代表「這裡一定有魚」
- **在你沒去過的新海域，AI 預測可能不準**——這時請忽略 AI 評分數字，改看水溫鋒面圖和洋流圖（物理層資訊），配合自身經驗判斷
- **不能告訴你「今天不適合出海捕魚」**——系統每天都會選出相對最好的漁場，即使整體條件很差
- **深度學習模型目前沒有在運作**——ConvLSTM、U-Net、TransFish 這些名字出現在系統裡，但還沒有接上實際預測
- **⚠️ 預測模型層級說明**——儀表板上每個漁場推薦旁會顯示模型標記，代表不同的預測來源：
  - 「🤖 ML-44」= 主模型（59 特徵機器學習 + 物理融合），正常狀態，可參考 AI 評分排名
  - 「⚠️ ML-12 降級」= 主模型發生錯誤，自動切換至精簡版 12 特徵模型。預測精度較低，**建議以鋒面、水溫圖等物理海洋資訊為主要判斷依據**
  - 「📐 純物理」= 該物種無 ML 模型（未訓練），預測僅基於海洋學理論公式（SST、鋒面、渦旋等）。**評分反映的是物理環境適合度，不含統計學習成分，請結合自身經驗使用**

**💡 建議使用方式：**
- 把系統的推薦**當成參考，結合自己的經驗判斷**
- **物理海洋資訊（鋒面、水溫、洋流）是最可靠的部分**，可以信賴
- AI 分數當作「相對排名」看——哪個點比其他點好，而不是這個點「多好」
- 每次航次回來後回報漁獲，資料會被蒐集起來，未來用來改進系統

## 十三、運作流程（船東視角）

```
每日凌晨自動執行
      ↓
[1] 擷取 12+ 種衛星資料
      ↓
[2] 物理海洋分析（鋒面、渦旋、溫躍層...）
      ↓
[3] 生態模型計算（食物鏈、棲地適合度）
      ↓
[4] AI 預測（59 維特徵 → Stacking Ensemble）
      ↓
[5] 安全過濾（排除危險海域、禁漁區）
      ↓
[6] 輸出 → 儀表板 + KML + 衛星簡報
      ↓
船長收到每日漁場推薦 → 出航 → 回報漁獲 → 資料蓄積（供未來模型改進）
```
