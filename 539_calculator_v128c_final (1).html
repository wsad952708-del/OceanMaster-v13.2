📖 程式完整教學（含限支數 / 電接射 / 跑馬燈降倍 / 中降倍拆解）
① 客戶管理 ＆ 同名分張
  • 新增客戶：左下「＋ 新增客戶」
  • 同名分張：每筆客戶卡右側「＋」按鈕 = 同名 +1，例如 阿姨 → 阿姨1 → 阿姨2…（同一個人下多張不同單）
  • 分張頁碼：同名群組超過 1 張時，卡片上會顯示 3/1、3/2、3/3（共幾張 / 這是第幾張）
  • 切換客戶：點側邊卡片，或鍵盤 TAB / Shift+TAB
  • 重新命名：點上方客戶名稱
  • 計價設定（直式 💰設定 按鈕）：每組共用一份「客戶計價」— 每支該賠多少錢給客戶
② 碰數計算系統
  • 二星 / 三星 / 四星：依輸入號碼自動算出碰數（C(n,2)、C(n,3)、C(n,4)）
  • 連碰：把所有號碼互相搭配
  • 立柱（用 ++ 分組）：各組獨立互碰，組間不互碰
  • 頭尾：1+ 自動展開為 10,11,12,…,19；-1 展開為 01,11,21,31
  • 支數倍率：可一次輸入 0.1（只二星）、0.10.2（二三星）、0.10.20.01（二三四星）
  • 中獎號碼會自動標記：開獎後對中的號碼會以金黃底黑字標出 — 主畫面、注單明細、匯出報表都一致
  • ❗ 輸錯按 * 回上一步（限於輸入流程中，不會刪除已下注清單）：
    • 號碼按 Enter 進二星支數 → 號碼錯了 → 按 * 回號碼步驟，原號碼還原可改
    • 二星按 Enter 進三星 → 二星打錯 → 按 * 回二星支數重打
    • 同理三星→二星、四星→三星，每步都能按 * 退
    • 專車/台號/特尾：支數步驟按 * 回號碼步驟，原號碼還原可改
    • 已 Enter 完成的下注 → 請點該筆 entry 右側的 × 刪除，* 不會動到它
    • − 跟 * 效果一樣（看哪個鍵順手）
③ 頂部功能列
  • 💰 價差營利：設「我的本錢」— 客戶計價跟本錢的差額就是個人收益（不影響上手對帳）
  • 📊 客戶盈虧：每位客戶 / 群組 / 上手 / 上手→客戶（pair） / 多上手混看（mixpair） 的輸贏明細，可下載 PDF；點「📋 注單明細」開啟單張詳細注單清單
  • 📈 客戶佔成：上手抽成 % — 1 成 = 10%，同類別最高 10 成（100%）— 超過會即時警告且鎖住儲存鍵
  • ⚠ 降倍號碼：特定號碼降低賠率（最多 3 批次）— 中獎時注單右側「中降倍」徽章會分別列出二/三/四星的金額與降賠率(N) 標籤；本單合計橫條也會跑馬燈滾動啟用中的降倍批次
  • 🎯 開獎號碼：本期 5 個獎號（01-39），會即時算出中獎
  • 🎯 台號賠率 / 特尾賠率：個別號碼可自訂賠率
  • 📒 帳目比對：誰需要付給誰多少錢（含上手佔成 + 價差營利）— 支援下載 PDF
  • 📡 電接射：射出 + 接射兩功能合在一顆按鈕；打開後 modal 上方有雙分頁可切，紅點 N 顯示收件匣待處理數（詳見 ⑦）
  • 📊 限支數：設定每組號碼最多收幾支，超過直接擋下下注 + 中文女聲播報（詳見 ⑩）
  • 🏆 收量排行：分頁查看每類別目前哪些號碼吃最多，前 3 名強調（詳見 ⑫）
  • 📄 匯出：匯出 PDF 報表（個別客戶 / 群組 / 上手等範圍可選）
④ 客戶盈虧 — 範圍下拉的選項
  • 全部：所有有下注的客戶/群組
  • 上手 → 客戶（pair）：例如「阿狗 → 阿伯」— 只看阿伯這位客戶對阿狗這位上手的份額； 已修正不會被其他上手干擾
  • 🔀 多上手混看（mixpair）：例如「阿狗+淑美 → 阿伯」— 同一客戶綁多位上手時，把所有上手對該客戶的份額合看；只有該客戶有 2 位以上上手時才會出現
  • 選了範圍 → 上方摘要、上手匯總、底部總計都會自動套用
⑤ 佔成（上手抽成）規則
  • 單位「成」：1 成 = 10%，0.1 成 = 1%，0.01 成 = 0.1%；可小數點（0.2、1.5 成都可）
  • 每個類別（二/三/四星、專車、台號、特尾）獨立設定
  • 同類別最高 10 成上限（100%）— 輸入時就即時警告 + 鎖住儲存鍵，無法超過
  • 群組設定 = 整組共用；個別客戶可獨立覆寫
  • 「⚙ 管理」按鈕已改名為「＋ 新增名單」（管理上手名單）
⑥ 價差營利計算
  • 價差/支 = 客戶計價 − 我的本錢
  • 群組價差 = 價差/支 × 該類別支數（專車 ×38 倍）
  • 沒設本錢（空白）= 不計入；客戶計價也是 0 = 不計入
  • 價差是純個人收益，不出現在客戶/上手對帳，也不會匯出
⑦ 📡 電接射（射出 ＆ 接射合併）
  • 合併按鈕：原本兩個「📤 射出」「📥 接射」合併成單一「📡 電接射」按鈕；點開後 modal 上方有「📤 射出 / 📥 接射」雙分頁可切，紅點 N 在按鈕右上顯示收件匣待處理數
  • 我的帳號名稱：在 📡 電接射 → 接射分頁頂端設定（例：主帳號、子帳A、阿宏）— 對方在「射出」要選你的名字才能推送過來
  • 射出：分頁 📤 射出 → 選接收帳號 → 勾客戶 → 確認射出（單推送到對方收件匣 + 同時下載 .json 備援檔到桌面）
  • 接射：分頁 📥 接射 即看到收件匣；點預覽 → ✓ 同意接收 或 ✗ 拒絕
  • 對象開關：每位帳號兩個開關 — ✓ 可接射（對方能射給我）與 📤 可射出（我能射給對方）
  • 備援匯入：對方離線/跨機器時，可用「📁 備援匯入 .json」（在收件匣下方），匯入後一樣進收件匣
  • 有設佔成 → 只射出「上手部分」（1 − 佔成%），本機保留佔成部分；沒設佔成 → 整張轉走
⑧ 註記（📝 加註記）
  • 輸入區下方「📝 加註記」按鈕 — 點下去輸入文字 → 立即卡入清單（含當下時間）
  • 用途：同一張單裡，不同人合併計算、人工備註、分段標記都可以用
  • 註記是黃條樣式，可以隨時用 ✕ 刪除
⑨ 介面操作小技巧
  • 本頁清除：輸入區右下角「本頁清除」清空當前選中客戶的下注（其他客戶不受影響）；要刪整位客戶用左側卡片的 ✕
  • 同名 +1：客戶卡右側「＋」立刻多開一張同名單（阿姨1 → 阿姨2 …）
  • 教學區可收合：右上「▲ 收合」按鈕一鍵藏起本教學區
  • 輸完號碼按 Enter 不是送出 — 是進到支數輸入步驟，再 Enter 才確定
  • 支數步驟想回去改號碼 → 按 −（減號）或 *（星號）
    例：輸完號碼按 Enter → 跑二星倍率時發現號碼打錯 → 按 * 退回號碼步驟改
  • 客戶有設佔成 → 「客戶盈虧」會把上手該收的金額自動扣出來
  • 帳目比對會自動列出最少筆數的金流（A 付 B 多少），不會囉嗦列每一筆
⑩ 📊 限支數（控管每組號碼最多收幾支）
  • 開啟設定：頂部「📊 限支數」按鈕（在 📡 電接射 右邊）；有超滿時按鈕會亮紅點
  • 六個分頁：🎯 二星 / 🎯 三星 / 🎯 四星 / 🚗 專車 / 🎯 台號 / 🎯 特尾，每個分頁分開設
  • 個別組合限額：例如二星分頁輸入 15 17 + 限額 1000 → 該組（15,17）累計超過 1000 支就擋下
  • 輸入彈性：15 17 / 15,17 / 15.17 / 1517 都接受
  • 「全部」每組上限：每個分頁最上方綠色卡片，可設「該類別每組號碼的預設上限」。例如「全部二星 100 支」= 每一組二星最多收 100 支（不是所有二星加總 100）
  • 個別 + 全部優先順序：個別設定優先 → 沒設個別才套用「全部」預設。例：全部=100，個別 15.17=50 → 15.17 用 50，其他組用 100
  • 超滿就擋下：下注時自動算「這筆加進去會不會超」，超過 → 整筆下注沒成功 + 跳 alert + 右上紅 toast + 中文女聲播報「下注沒成功，二星15.17超出限額」。若是「全部XX」總額超出，會列出本筆涉及的具體號碼組合
  • 剛好打滿：金色柔性 toast 提示「剛好打滿」，仍允許這筆下注
  • 清除：modal 底部「🗑 單頁清除」（只清這分頁含全部限額）、「🗑 全部清除」（6 分頁全清）
  • 支數計算：連碰/立柱會展開所有組合，每組合 ×「該星支數倍率」累計
⑪ 中降倍拆解 ＆ 跑馬燈
  • 每筆中獎金額拆星：注單右側「中降倍」徽章會分別列出 二星 / 三星 / 四星 的中獎金額與「降賠率(N)」標籤，看一眼就知道是哪一批降倍套用
  • 本單合計跑馬燈：上方「本單合計」橫條會跑馬燈滾動目前啟用的降倍批次（號碼 + 賠率倍率），滑鼠移上去會暫停
  • 降賠率徽章：降倍號碼相關提示都改成金色漸層跑馬燈樣式，更醒目
⑫ 🏆 收量排行（查看哪些號碼吃最多）
  • 開啟方式：頂部「🏆 收量排行」按鈕（在 📊 限支數 右邊）
  • 分頁切換：上方 6 個分頁 — 🚗 專車 / 🎯 二星 / 🎯 三星 / 🎯 四星 / 🎯 台號 / 🎯 特尾，每個分頁右上紫色徽章顯示組數
  • 橫向膠囊格子：每格顯示「#排名 ｜ 號碼 ｜ 支數」，由多到少排序；單號類 6 欄、二星 5 欄、三/四星 4 欄
  • 排序方向：由上而下、再由左至右（column-major）— #1 在左上、#2 在 #1 正下方、依序往下；填滿一欄再跳到下一欄
  • 前 3 名強調：🔴 第一名紅底 / 🟠 第二名橘底 / 🟡 第三名金底，加大字級
  • 排序順序：依使用者習慣，專車 → 二星 → 三星 → 四星 → 台號 → 特尾
  • 自動開到第一個有資料的分頁；很多組（如三星上百組）時 modal 內側自動出捲軸
  • 純檢視不會改任何資料，每次開啟即時重算

  • 需要先有過任何互動（瀏覽器規定：頁面開啟後點過任何按鈕，語音才能播）
⑭ ✋ 手動下注（用滑鼠選號碼，免打字）
  • 開啟方式：輸入區頂部、「本頁清除」按鈕左邊的「✋ 手動下注」紫色按鈕
  • 5 個模式：🎯 連碰 / 📊 立柱 / 🚗 專車 / 🎯 台號 / 🎯 特尾，上方分頁切換
  • 連碰：01–39 格子可複選，選好按「✓ 送入下一步」會自動填到主輸入框並送出（後面支數倍率走原本流程）
  • 立柱：同 01–39，但選的號碼用不同顏色標出當前是哪一柱；按「＋ 分柱」開新一柱；確認後產生 0105+1112 格式
  • 頭/尾擴展（連碰/立柱）：「0+」一鍵加 01~09、「1+」加 11~19，「-7」加 07,17,27,37 之類；可重複按多個
  • 專車：01–39 單選 + 支數輸入框
