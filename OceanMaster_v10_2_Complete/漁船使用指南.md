# 🎣 OceanMaster 漁船導航系統 - 完整使用指南

## 📱 給漁船船長的快速指南

### 🚀 第一次啟動（只需要做一次）

**步驟 1: 開啟 Windows PowerShell 或命令提示字元**
- 按 `Win + R`
- 輸入 `cmd` 然後按 Enter

**步驟 2: 切換到程式目錄**
```bash
cd C:\Users\user\Desktop\好像快好了\OceanMaster_v10_2_Complete
```

**步驟 3: 安裝必要套件（只需要做一次）**
```bash
pip install fastapi uvicorn apscheduler --break-system-packages
```

**步驟 4: 啟動系統**
```bash
python web_server.py
```

### 🌐 使用網頁查看漁場

啟動後，在瀏覽器輸入：
```
http://localhost:8000
```

您會看到：
- 📍 **互動地圖**：顯示所有漁場熱點
- 📊 **熱點排名**：Top 10 最佳漁場
- 🔄 **自動更新**：系統每 6 小時自動更新
- 📱 **手機也能用**：手機瀏覽器也可以開啟

## 🎯 網頁功能說明

### 主要功能

#### 1. 互動式地圖
- **綠色標記** = HSI ≥80% (最佳漁場)
- **黃色標記** = HSI 65-79% (優秀漁場)
- **橙色標記** = HSI 50-64% (良好漁場)
- 點擊標記可以看到詳細資訊

#### 2. 熱點列表（右側）
顯示 Top 10 漁場，包含：
- **排名編號**
- **物種類型** (黃鰭鮪、大目鮪等)
- **HSI 分數** (越高越好)
- **位置座標** (緯度、經度)
- **距離和航行時間**
- **水深和 EEZ 資訊**
- **海洋參數** (溫度、代謝指數等)

點擊任何卡片，地圖會自動跳到該位置！

#### 3. 自動更新狀態
頂部會顯示：
- ✅ 最後更新時間
- 📊 熱點數量
- ⏰ 下次更新時間
- 🔄 更新進行中提示

## 📊 如何看懂漁場資訊

### HSI 分數（棲地適宜性指數）
```
≥80%  →  🟢 最佳 - 強烈推薦
65-79% →  🟡 優秀 - 推薦
50-64% →  🟠 良好 - 可考慮
<50%   →  ⚪ 一般 - 不建議
```

### 關鍵參數說明

| 參數 | 說明 | 理想值 |
|------|------|--------|
| **HSI** | 總合評分 | 越高越好 |
| **Φ (代謝指數)** | 魚類生理狀態 | 4-6 最佳 |
| **SST** | 海表溫度 | 依物種而定 |
| **距離** | 從基地到漁場 | 越近越省油 |
| **航行時間** | 預估時間 | 以 10 節計算 |
| **EEZ** | 法律區域 | 公海優先 |

### 物種偏好

| 物種 | 最適溫度 | 深度範圍 | 特性 |
|------|----------|----------|------|
| 黃鰭鮪 | 24-28°C | 0-200m | 表層，溫暖 |
| 大目鮪 | 18-24°C | 100-400m | 中深層 |
| 正鰹 | 25-30°C | 0-100m | 表層，高溫 |
| 長鰭鮪 | 15-20°C | 0-250m | 溫帶 |
| 柔魚 | 18-22°C | 100-300m | 中深層 |
| 赤魷 | 10-18°C | 200-600m | 深層，低溫 |

## 🔄 自動更新機制

### 更新時間表

| 時間 | 動作 | 說明 |
|------|------|------|
| **每天 02:00 UTC** | 完整分析 | 重新計算所有數據 |
| **每 6 小時** | 快速更新 | 更新 SST + 海流 |
| **網頁每 5 分鐘** | 自動刷新 | 確保顯示最新數據 |

*UTC 時間 = 台灣時間 - 8 小時*
*例如：UTC 02:00 = 台灣時間 10:00*

**方法 2: 重新執行**
```bash

cd C:\Users\user\Desktop\好像快好了\OceanMaster_v10_2_Complete
python main_v10_2.py --run-now
```

## 💡 實際使用範例

### 情境 1: 每天早上查看今日漁場

1. **打開瀏覽器** → 輸入 `http://localhost:8000`

1. **確保電腦和手機在同一 WiFi**

3. **手機瀏覽器輸入**：`http://電腦IP:8000`
4. **隨時查看** → 在船上也能看

## 🛠️ 故障排除

### 問題 1: 網頁打不開

**解決方法:**
```bash
# 檢查程式是否在運行
# 應該看到類似這樣的訊息：
# INFO:     Uvicorn running on http://0.0.0.0:8000
```

如果沒有，重新執行：
```bash
python web_server.py
```

### 問題 2: 顯示「載入中」很久

**原因:** 系統正在執行第一次分析（需要幾分鐘）

**解決方法:** 耐心等待，或者檢查 PowerShell 視窗的進度

### 問題 3: 數據很舊

**檢查:**
```
http://localhost:8000/api/status
```

**手動更新:**
```bash
# 開新視窗
python main_v10_2.py --run-now
```

### 問題 4: Port 8000 被佔用

**修改 web_server.py 最後一行:**
```python
uvicorn.run(app, host="0.0.0.0", port=8080)  # 改成 8080
```

然後瀏覽器改用：`http://localhost:8080`

## 📱 讓手機也能看（進階）

### 區域網路設定

**步驟 1: 查詢電腦 IP**
```bash
ipconfig
```
找到類似 `192.168.x.x` 的 IPv4 位址

**步驟 2: 手機連同一個 WiFi**

**步驟 3: 手機瀏覽器輸入**
```
http://192.168.x.x:8000
```

### 外網訪問（需要進階設定）

如果要在海上用 4G/5G 查看，需要：
1. 申請固定 IP 或使用 DDNS
2. 設定路由器 Port Forwarding
3. 考慮安全性（設定密碼）

*建議找專業人員協助設定*
